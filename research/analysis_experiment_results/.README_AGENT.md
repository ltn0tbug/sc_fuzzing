# `research/analysis_experiment_results/` — filled experiment-analysis reports

The four **results-only** reports for the current experiment run, generated from
`research/template/` + the `src/experiment/eda/` scripts. This is the *filled* edition
(numbers + figures); the stripped skeletons live in `research/template/`.

Generated 2026-07-18 from the completed 12-run sweep (6 methods × {defihacklabs N=25,
smartbugs N=33}). SSCFuzz here = `sscfuzz_esb` (the switching-bandit selector, the default
`sscfuzz` alias); the analysis scripts read it via an `output/experiment/<ds>/sscfuzz →
sscfuzz_esb` symlink (gitignored `output/`).

**LLM-backend-size comparison runs through Part B** (each method × 1.5B/3B/7B its own series) from
`model_compare.py`: expanded **B1–B8** — B1 (table + bars), B2 growth, B3 box, B4 KM, B5 table (SSCFuzz·1.5B
vs every method×size), B6 per-contract heatmap + complementarity, B7 cost, B8 class×method×size heatmap
(`*_by_model.png` + `B{1,5}_by_model.csv` + `B6_complementarity_by_model.csv`). 1.5B = base
`output/experiment/`, 3B/7B = sibling `output/experiment_llama{3b,7b}/` (model-varying methods
`madfuzz`/`llmfuzz`/`sscfuzz` only). 7B: SSCFuzz + LLMFuzz complete (both datasets); MADFuzz not run → `—`.
Only B9/B10 + Parts C–E stay 1.5B; **Part A is model-independent** (dataset EDA). Method row order (all files) =
`randomfuzz · financefuzz · rlfuzz · madfuzz · llmfuzz · sscfuzz`.

## The four files — one role each (governed by `rule/update_analysis_reports.md`)
| File | Corpus / role |
|---|---|
| `experiment_analysis_defihacklabs.md` | DeFiHackLabs only (N=25) |
| `experiment_analysis_smartbugs.md` | SmartBugs-Curated only (N=33) |
| `experiment_analysis_combined.md` | the two side-by-side (both corpora as columns) |
| `experiment_analysis_pooled.md` | both pooled as one N=58 corpus |

All four carry the **identical A1–E3 skeleton**; keep them synced (rule
`rule/update_analysis_reports.md`). Every section is a table or figure + a *how-to-read*
caption only — no interpretation (that lives in `research/research.md` + the paper).

## Figures
Reports reference `../figures/{experiment,experiment_smartbugs,experiment_combined}/…` and
the flat `../figures/A1_vuln_distribution*.png`. Those are regenerated per run by the
`src/experiment/eda/` battery — see [regenerate](#regenerate).

## Regenerate (from repo root)
```
uv run python src/experiment/eda/exp_analysis.py {defihacklabs,smartbugs,all}   # A–C, B
uv run python src/experiment/eda/model_compare.py {defihacklabs,smartbugs,all}  # B1 per-model (1.5B/3B/7B) → B1_by_model.csv
uv run python src/experiment/eda/eda_enrich_partA.py                            # A1 + feature stats
uv run python src/experiment/eda/sscfuzz_internals.py {defihacklabs,smartbugs,all}  # Part D
uv run python src/experiment/eda/oracle_precision.py {defihacklabs,smartbugs,all}   # Part E
uv run python src/experiment/eda/vuln_type_analysis.py                          # per-class CSVs
```
Then transcribe the emitted figures/CSVs (and each dir's `_report_blob.json`) into the
templates. Workflow + no-drift rules: `rule/update_analysis_reports.md`.
