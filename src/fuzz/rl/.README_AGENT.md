# rl/ — DQN controller · replay · reward signal

Open when editing **strategy selection / DQN / replay / how reward shapes search**. Reward is
computed in `../fuzzer/reward.py` and state in `../fuzzer/state.py`, but their *semantics* are here.

Files: `network.py` (DQN, 2-layer MLP) · `replay_buffer.py` (uniform + PER) · `controller.py`
(`RLController`: `select_strategy(valid_actions)` · `store` · `train_step` · `observe_outcome` (no-op) ·
`save`/`load` model + `state_dict`/`load_state_dict` = FULL learner for iteration-level checkpointing incl.
replay/n-step/rms) · `bandit.py` (`BanditController` + `make_controller(config)` factory) ·
`contextual_bandit.py` (`ContextualBanditController` — disjoint LinUCB, `sscfuzz_cb`).
Learning telemetry: `select_strategy` records `last_q_chosen` (None on ε-random), `train_step` records
`last_loss` — the loops read these + `epsilon` into the run-log `learning` block (see `../report.py`).

## Selectors (SScFuzz)
`orchestrator.py` builds the selector via **`make_controller(config.rl)`** (not `RLController(...)`
directly), dispatching on `RLConfig.selector`. All default-neutral → baselines unchanged.
The loop is polymorphic over `select_strategy`/`store`/`train_step`/`observe_outcome`/`state_dict`.
The registry method name **`sscfuzz` is an ALIAS → `sscfuzz_esb`** (the switching bandit — the
RQ3a-recommended selector; `registry.METHOD_ALIASES`). The DQN below keeps the explicit name `sscfuzz_dqn`.
- **`sscfuzz_dqn`** (the former default `sscfuzz`) — `selector="dqn"` + **`factored_head=True`**: the **factored shared-per-arm
  head** (`network.py`) over the StateEncoder **per-arm layout** — global-context block (`N_GLOBAL=7`) +
  one `ARM_FEAT=5` tuple per active arm `(tanh avg_reward, tanh mrew, dry, bug_trace, is_mut)`. One shared
  sub-net scores every arm from its tuple + global context, pooling the "pick a rising / not-dried arm"
  rule across arms (anti-starvation a flat MLP can't do; folds in the retired `sscfuzz_ms` mrew/dry as
  tuple features). **state 52** = 7 + 5·9 for the 5-gen+4-mut roster; `n_global`/`arm_feat` synced from the
  encoder instance like `state_dim`. Selector-rework 2026-07-10 (backup tag `sharedhead-backup-2026-07-10`).
- **`sscfuzz_esb`** (`SScFuzzESBDefaults`) — `selector="bandit"` → **`BanditController`** (no neural net):
  a non-stationary Exhaustion-Switching Bandit over the compact action table. Per-arm `ewma`
  (`bandit_ewma_alpha`), `dry`, `pinned` (banked an exploit), `cooldown`. Picks the EWMA-argmax
  incumbent (pinned arms lead) with prob 1−`bandit_epsilon`, else an ε-probe; after `bandit_giveup`
  unproductive picks eliminates an arm (`bandit_cooldown` pulls) and falls to the next. `store`/
  `train_step` no-op; telemetry `epsilon=bandit_epsilon`, `last_loss=None`. Keeps the two-tier reward.
  Uses the block layout (`per_arm_layout` off) but discards the state vector.
- **`sscfuzz_cb`** (`SScFuzzCBDefaults`) — `selector="linucb"` + **`emit_static=True`** →
  **`ContextualBanditController`** (disjoint **LinUCB**, `contextual_bandit.py`, no neural net) over the
  StateEncoder **context layout** (`context_layout` — the global block ONLY + F1 when `emit_static`, an
  arm-INDEPENDENT context `x`). Each arm has its own discounted linear model: `A_a=λI`, `b_a=0`,
  select = argmax `θ_aᵀx + linucb_alpha·√(xᵀA_a⁻¹x)`; the update is done IN `store` every iter (incl.
  warmup): `A_a ← γA_a + xxᵀ + (1−γ)λI`, `b_a ← γb_a + r·x` (`γ`=`linucb_discount` forgets stale
  evidence). `train_step`/`observe_outcome` no-op; telemetry `epsilon=0`, `last_q_chosen`=chosen UCB
  score. `save`/`load` persist per-arm `A_a`/`b_a` = the **cross-contract transfer** (the RQ3a §7.4(ii)′
  answer: F1 in `x` routes per-strategy via θ_a where the collapsing DQN could not). Selector-rework
  2026-07-13 (backup tag `contextual-bandit-backup-2026-07-13`).
- **`observe_outcome(action_idx, reward, found_new, banked)`** — called EVERY iter (incl. warmup) after
  `state_enc.update(...)`; no-op on the DQN, folds the outcome into the bandit's per-arm bookkeeping.
  Registry method `sscfuzz_esb` reuses `run_fuzzing_loop`; results write to its own dir. (The retired
  `sscfuzz_ms` separate-block `emit_marginal` ablation was removed — its `mrew`/`dry` are now per-arm tuple features.)

## Reward = the search signal, not detection
`result.bug_signal_found` (in `../fuzzer/`) set whenever a `BUG_SIGNAL:` appears (always reported).
**`new_exploit_path`** = the **path-gated 0/1** driving reward: `_score_bug_novelty` banks the path in
`_rewarded_exploit_paths` and pays a **tiered** bug score **only the first time a distinct path is seen** —
**+50** if any signal is `tier=high` (`attacker_profit`/`target_loss`, a proved net impact →
`result.high_bug_signal_found`), else **+5** for a heuristic-only path (a suspicious balance move that might be
a fair trade).
- **PER RUN = the MAX tier, never per-signal:** a run tripping several BUG_SIGNALs at once (e.g.
  `attacker_profit`+`target_drained`) banks one path, pays one score = the max tier (+50), never
  score × signals. `new_exploit_path` is 0/1, not a count.
- coverage = **bytecode-level** branches, size-normed by `bc_branches_total`. (On a fork
  `bc_branches_total` is anchored on the ON-CHAIN bytecode — the reported ratio changed, so fork
  reward/coverage numbers don't pool with pre-coverage-fidelity runs. See `../fuzzer/.README_AGENT.md`.)
- **RL Iter 7 two-tier coverage (SScFuzz-only, `two_tier_cov`).** The single shared coverage term is
  the LEGACY/baseline path (RLFuzz/MADFuzz/LLMFuzz keep it via compute_reward's default). SScFuzz's
  orchestrator passes `two_tier=True` → coverage splits into (1) a small PER-STRATEGY **base**
  (`cov_ps_rate`·branches-new-to-THIS-pick-label / total — anti-starvation, always paid, so a late
  vuln strategy is never zeroed on already-globally-seen branches) + (2) a larger GLOBAL-new **bonus**
  (`cov_global_rate`·new_bc_branches / total) **gated** by (past the round-robin warmup AND
  `stuck_before ≥ unstick_min`) and amplified by the plateau multiplier — only hard-won post-plateau
  global advances pay, so the easy early sweep crowns no lottery winner. `orchestrator.py` owns
  `seen_bc_by_strategy` (keyed by pick label) and computes `per_strat_new`; foundry's
  `_seen_bc_branch_ids` stays the honest-coverage set. The two-tier path DROPS the `_novelty` term
  (per-strategy coverage subsumes it — RL Iter 7 C4); novelty is retained ONLY on the legacy path.
- **Novelty (legacy path only)** = new `(jpc,dir)` vs one seed, mutate-mode only, ≤10.
- `paths.is_distinct_path` (Jaccard < 0.9) = shared "distinct exploit" def (reward gate + corpus Group B).
- `compute_reward(result, strategy, seed_branches, mode, stuck_before, unstick_*, two_tier, per_strat_new,
  in_warmup, cov_ps_rate, cov_global_rate, bug_scale)` in `../fuzzer/reward.py` — the `unstick_*` +
  two-tier params are threaded from `RLConfig`/`orchestrator.py`, which reads `state_enc._stuck_counter`
  BEFORE `update()` for `stuck_before`. Default (`two_tier=False`) = the unchanged legacy path.

## State → action
`state(≤46-dim) → controller.select_strategy(valid_actions) → action = index into _action_table`.
**Action table (RL Iter 6 hard resize):** `orchestrator.py` builds a compact `_action_table =
[("generate",g) for g in active_gen] + [("mutate",m) for m in active_mut]` from the roster left after
`FuzzerConfig.disabled_strategies` — the DQN head has ONE output per legal action, no dead masked
outputs. `action_dim` is synced from `len(_action_table)` before the DQN is built (same instance-driven
pattern as `state_dim`); SScFuzz's **8-name blocklist → action_dim 9** (5 gen + 4 mut; RL Iter 7 C2 also
gates `exploration`), empty blocklist → the full 17 (ablation). The mut tail (indices ≥ len(active_gen)) is masked to −∞ until
`len(corpus) ≥ mutation_min_corpus_size`. **State gate (RL Iter 4):** `disabled_strategies` also removes
each disabled *generation* strategy's per-strategy reward dim from the state. **Mut reward block (RL Iter
5):** the ACTIVE *mutation* strategies get their own per-strategy reward dim (`active_mut_mask`) —
`update(…, mut_idx=)` credits the mut slot in mutation mode (mut_idx derived from
`MUTATION_STRATEGIES.index(name)`, not the table offset). **Dynamic-decision reshape (RL Iter 6):** the 5
static contract features (constant within a run → dead dims; gated behind `emit_static`, default off) and
the 2 heat-map aggregates (duplicated coverage_ratio) LEFT the emitted vector; `gen_stall`/`mut_stall`
(iters since a gen/mut action last found a new bc-branch — the gen-vs-mut discriminator) and
`seed_pool_value_mean/best` (set from `mutator._corpus`) JOINED it. **RL Iter 7 C3** ADDS a decaying
per-active-strategy **bug-success trace** block (gen then mut, gated behind `emit_bug_trace`/`RLConfig.bug_trace`)
that bumps on a novel exploit bank and fades ×`bug_trace_decay` each round — durable Layer-2 steering after
the one-shot bug reward evaporates. That block layout (used by the baselines' full-roster ablation and by
`sscfuzz_esb`, which discards the vector): gen-only full roster, flags off = 17.
**`sscfuzz` uses the PER-ARM layout instead** (`per_arm_layout`, driven by `factored_head`): a global-context
block (`N_GLOBAL=7`: cov_ratio, velocity, frontier_sat, corpus_maturity, gen_stall, mut_stall, seed_pool_best)
+ one `ARM_FEAT=5` tuple per active arm `(tanh avg_reward, tanh mrew, dry, bug_trace, is_mut)`, gen slots then
mut slots (matching the action table) → **52-dim** (7 + 5·9). Drops revert (measured non-contributing), stuck
(subsumed by gen/mut_stall), seed_pool_mean (co-moves with best). The **factored head** (`network.py`) reshapes
`[n_global | n_arms·arm_feat]` and runs a shared per-arm sub-net → per-arm advantage + a global value stream.
(The retired `sscfuzz_ms` separate-block `emit_marginal` ablation was removed; its `mrew`/`dry` are the arm-tuple recency/exhaustion features.)
Encoder takes `active_gen_mask` + `active_mut_mask`; `update(…, banked_exploit=)` remaps a full
gen index → compact slot via `_slot_of`, a full mut index → mut slot via `_mut_slot_of` (same routing feeds
the bug-trace bump + mrew/dry). Strategy roster → `../llm/`; encoder → `../fuzzer/state.py`.
**`RLConfig.state_dim`/`action_dim` (and `n_global`/`arm_feat` for the factored head) overwritten from the
encoder INSTANCE / `len(_action_table)` in `orchestrator.py`** after the encoder is built and before the DQN
is built (layout can't desync the net).
