# src/fuzz/ — module hub

Splits *what to attack* (RL) from *how* (LLM), run on EVM (Foundry). Open the one submodule for
your task:
- `rl/.README_AGENT.md` — DQN · replay · **reward as search signal** · design numbers.
- `llm/.README_AGENT.md` — 17 strategies · prompts · backends · output contract.
- `fuzzer/.README_AGENT.md` — execution · **financial-loss oracle** · coverage · corpus · templates · ctor/dep deploy.

Top-level files:
- `config.py` — `RLConfig`·`LLMConfig`·`FuzzerConfig`·`ForkConfig`. **Schema only**, no defaults.
- `profiles.py` — per-method **defaults** (`<method>_defaults`); `.materialize(mode=…)`→cfg. CLI
  defaults + the experiment runner both read these → change defaults here, not `config.py`. Includes the
  the SScFuzz selector variants `sscfuzz_esb_defaults` (`selector="bandit"`) and `sscfuzz_cb_defaults`
  (`selector="linucb"` + `emit_static=True`, the disjoint-LinUCB contextual bandit), both subclassing
  `SScFuzzDefaults` (override only `rl`). `SScFuzzDefaults` itself now sets `factored_head=True` (the
  shared-per-arm-head DQN; folds in the retired `sscfuzz_ms` recency/exhaustion signals as per-arm tuple features).
- `report.py` — `ReportSpec`+`REPORT_SPECS`: single source gating **both** console panels **and**
  run-log/bug JSON fields per method. New JSON field = 1 bool on `ReportSpec` + 1 branch in the builder.
  Per-iter `fuzzing_output` is built once by `build_fuzzing_output(reward, result)` (shared by
  orchestrator.py + baseline loop.py): detection keys `signal_found`/`high_bug_signal_found`/`novel_path`/`signals` (structured,
  supersedes `bug_type`); `bug_found`/`bug_type` kept as legacy analysis aliases.
  Every run record carries a universal `learning` block (cum_reward / cum_unique_bc_branches / cum_bugs
  / wall_ms) + `log_learning_rl`-gated DQN telemetry (epsilon/td_loss/q_chosen, sscfuzz+rlfuzz+madfuzz);
  `build_run_summary` derives `learning_curve` (`_learning_curve`) from them.
- `checkpoint.py` — iteration-level resumable state (`save`/`load`/`clear`/`rng_state`), flushed every
  `checkpoint_every` iters by both loops (orchestrator.py + baselines/common/loop.py) so a killed run resumes
  mid-contract. Components expose `checkpoint_state()`/`restore_checkpoint_state()` (fuzzer coverage
  sets, encoder accumulators, corpus, LLM history) and `RLController.state_dict()`/`load_state_dict()`
  (net+target+optim+replay+n-step+rms). The growing **run-record log** is NOT in the checkpoint blob
  (would be O(n) mem + O(n²/interval) IO on long runs) — each record is appended to a sidecar
  `<safe_id>.records.jsonl` (`append_record`) and read back on resume (`load_records`, truncated to the
  checkpoint's iter so post-flush rolled-back records drop). `clear` removes both files. Runner
  (`experiment/run`) owns path + clear-on-completion. `FuzzerConfig.keep_checkpoint` (CLI
  `--keep-checkpoint`, needs a path): on CLEAN completion both loops write a FINAL checkpoint at the
  true last iter (not the last periodic flush) and it's NOT cleared, so a later higher-`max_iterations`
  run continues from the real end (100→200). Crash flushes stay transient. Standalone commands (all but
  financefuzz) expose `--checkpoint-path`/`--checkpoint-every`/`--keep-checkpoint`.
- `main.py` — CLI only (`sscfuzz·rlfuzz·madfuzz·randomfuzz·llmfuzz·financefuzz·init-project`): click
  group + option parsing + config build; each command calls into `orchestrator.py`. Re-exports
  `run_fuzzing_loop`/`build_bugs_payload` (registry + baseline loop import them from `fuzz.main`).
- `orchestrator.py` — the SScFuzz iteration driver (`run_fuzzing_loop`, the parallel of
  `baselines/common/loop.py`) + `build_bugs_payload`/`_tok_snap`. Overwrites `RLConfig.state_dim`
  from the `StateEncoder` instance (`state_enc.state_dim`), `RLConfig.action_dim` from `len(_action_table)`,
  and (for the factored head) `n_global`/`arm_feat`, after building the encoder and before building the DQN —
  the active roster + `per_arm_layout` set all four (SScFuzz → state **52**, action 9, n_global 7, arm_feat 5).
  Builds the selector via **`rl.make_controller(config.rl)`** (`selector="bandit"` → `BanditController`,
  `"linucb"` → `ContextualBanditController`, else `RLController` = the factored per-arm-head DQN for sscfuzz)
  and calls `rl.observe_outcome(...)` every iter (bandit hook, no-op on DQN/LinUCB). The `sscfuzz_esb` (bandit)
  and `sscfuzz_cb` (LinUCB) variants reuse this same loop — see `rl/.README_AGENT.md`.
- `baselines/` — `rlfuzz·madfuzz·randomfuzz·llmfuzz·financefuzz·common/`. `financefuzz` is a
  **competitor** (FinanceFuzz paper): own GA + financial-property oracle, forge only as EVM
  backend — see `baselines/financefuzz/.README_AGENT.md`. It has its own runner (differential
  T→T′ oracle doesn't fit `common/loop.py`'s single-run loop).

## Data flow (one iteration)
```
state(52, per-arm) → RL.select_strategy(valid_actions) → action = _action_table index   (mut tail masked until corpus ≥ min; SScFuzz active_dim=9)
  GEN (table[i]=("generate",g)): LLMGenerator.generate(g) → list[FuzzInput]
  MUT (table[i]=("mutate",m)): LLMMutator.sample_seed() + llm_mutate(seed, m)   [fallback: mutate() ABI-level]
→ FoundryFuzzer.run_input → FuzzResult (outcome + coverage from --debug --dump)
→ compute_reward(result, strategy, seed_branches, mode, stuck_before, unstick_*, two_tier, per_strat_new, in_warmup, cov_*, bug_scale)   # RL Iter 7 two-tier + unstick, SScFuzz-only (default two_tier=False = legacy path); orchestrator owns seen_bc_by_strategy + round-robin warmup
→ LLMMutator.add(CorpusEntry)            # unconditional; Group A/B(weak-signal witnesses) curation decides survival
→ state_enc.update(…, banked_exploit=)   # RL Iter 7 C3 bug-success trace + per-arm mrew/dry (feed the factored-head tuples)
→ RL.observe_outcome(action_idx, reward, found_new, banked)   # Option C bandit hook (no-op on DQN)
→ RL.store + RL.train_step + generator.record_run
```

## Add a baseline / method
- baseline: `baselines/<m>/{policy,runner}.py` · CLI cmd in `main.py` · `MethodSpec` in
  `src/experiment/run/registry.py` · smoke test in `tests/test_baselines.py`.
- experiment method: 1 `MethodSpec` in `src/experiment/run/registry.py` + `*_defaults` in `profiles.py`. No new runner.

Commands → `../../COMMANDS.md`; *why* → `research/research.md`.
