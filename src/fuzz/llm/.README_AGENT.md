# llm/ — strategies · prompts · backends · output contract

Open when editing **what the model produces / how / which backend**. The produced `FuzzInput` is
rendered+executed by `../fuzzer/` (call shape + declared-external there).

Files: `strategies.py` (`GENERATION_STRATEGIES`(7) · `MUTATION_STRATEGIES`(10) + prompt tables) ·
`agent.py` (`_LLMClient` + `FuzzInput`; re-export hub for the two modules below) · `backends.py` (3
backends + GBNF builder + `TokenUsage`/`LlamaTokenStats`) · `source_budget.py` (minify/ABI-sig/AST-slice/
budget, pure fns) · `generator.py` (`LLMGenerator.generate(strategy)` · `record_run` ·
`set_address_pool`) · `random_gen.py` (sscfuzz's non-LLM `random_fuzz_input` — boundary-value pools;
backs the ε-greedy random branch + LLM-exhausted fallback; addresses from the mode-aware
`fuzzer.arg_sampling.build_address_pool`) · `prompts/` (system·generation·mutation·seed_pool·chatml).
`LLMMutator` (corpus + ABI fallbacks + `llm_mutate`) lives in `../fuzzer/mutator.py`.

## 17 strategies
0–6 gen (strategy drives prompt); 7–16 mut (mut strategy drives prompt, seed's gen strategy = context).
mut masked to −∞ until `len(corpus) ≥ mutation_min_corpus_size`.
| idx | family | names |
|---|---|---|
| 0–6 | gen | reentrancy_probe · arithmetic_probe · access_control_probe · price_oracle_probe · logic_error_probe · boundary_values · exploration |
| 7–16 | mut | value_perturb · arg_boundary · caller_swap · call_insert · call_delete · call_shuffle · reentry_depth · arg_address · call_swap · arg_shuffle |

Indices above are FULL-roster positions (`GENERATION_STRATEGIES` / `MUTATION_STRATEGIES` order) — still
used for state reward slots + `MUTATION_STRATEGIES.index()`. The RL ACTION index is now a compact
`_action_table` slot (RL Iter 6), not these.

**Gate (RL Iter 1 prune + Iter 3 additions + Iter 6 resize):** `FuzzerConfig.disabled_strategies` removes
strategies from the active roster; `orchestrator.py` builds the compact `_action_table` from what's left
and syncs `action_dim = len(_action_table)` (a HARD resize, no longer a mask over a fixed 17). SScFuzz's
default blocklist (`profiles.py`) gates off the
5 dead mutations (`arg_boundary·caller_swap·call_delete·call_shuffle·reentry_depth`; note `caller_swap`
is now a structural **no-op** — the unified single attacker identity `attacker_address` leaves no second
caller to swap to) + `boundary_values`
(folded into `arithmetic_probe`) + `arg_address` (generalized by `arg_shuffle`) + **`exploration`** (RL Iter
7 C2 — pure breadth already supplied by the ε-random *input* injection + the per-strategy coverage base;
was the DQN's mis-concentration magnet) → **active roster 5 gen + 4 mut = 9** (mut = value_perturb ·
call_insert · **arg_shuffle** · **call_swap**). Empty blocklist = full-17 (baselines / ablation). `arithmetic_probe` (ex-`overflow_probe`) covers overflow/underflow **and**
numeric off-by-one / boundary; `call_swap` substitutes one call with a different ABI function; `arg_shuffle`
rewrites one argument of ANY type.
`LLMGenerator` = generate mode; `LLMMutator` (`../fuzzer/`) = mutate mode (same 8 also exist as
deterministic ABI-level fallbacks).

## Backends + sampling (`backends.py`, orchestrated by `agent.py`'s `_LLMClient`)
3 backends: `anthropic` (needs `ANTHROPIC_API_KEY`) · `claude-code` (Agent SDK, local `claude` CLI) ·
`llama-cpp` (local, GBNF-constrained). Also: source budgeting (`--max-source-chars`), GBNF builder.
- `temperature` (`LLMConfig`, default 0.7) **omitted** from request when `None` → backend default.
- **Prompt caching:** `complete(..., cache_prefix=context)` marks the stable contract-context prefix
  (source/ABI, identical across every strategy+iteration) as a cache breakpoint. `anthropic` splits it
  into a `cache_control:ephemeral` content block (also caches the `system` prompt before it); `llama-cpp`
  ignores it (caches implicitly via `cache_prompt`); `claude-code` ignores it (Agent SDK caches internally).
  Split is prefix-exact — the gen/mut templates lead with `{context}`, so `user.startswith(cache_prefix)`.
- greybox context = compact `format_abi_signatures` list (not a raw ABI JSON dump); whitebox = budgeted source.
- **History block (`_LLMClient.format_history`, gen+mut):** one prior attempt per line —
  `[n] caller:call(args)[ok|fail:reason]→… | <r>r +<br>br | signal=High|Heuristic|N [signed verdict] | desc="…"`.
  `signal` = the run's oracle-signal **tier** (from the emitted bug signal): `High` = confirmed net
  profit/loss, `Heuristic` = balance moved past a threshold (not yet proven theft), `N` = none. Headline
  picks one signal by priority `attacker_profit>target_loss>attacker_gained>target_drained` (amounts never
  summed) for the `[signed verdict]` detail; no per-iter signal count. Amount + currency MIRROR the
  winning line's SYMBOL (chain-aware): a High verdict is in the **native coin** (`target_asset`: ETH/BNB/…),
  adds `total_asset` as `, N assets`, and a
  target-side verdict appends `, attacker gain unconfirmed`. A Heuristic line shows the **native coin**
  (ETH/BNB/…) 18-dec-scaled, or, for an **ERC20**, the **raw base-unit** amount + the token
  symbol (or `UnknownERC20Token` — decimals unknown, so unscaled). Fail tags are POSITIONAL (by call
  index). `desc` = the attempt's own text
  (`N/A` for random/fallback). The column **legend lives in `SYSTEM_PROMPT`** (cached), not the
  uncached history tail. Sentinel hex args render symbolically (`max`/`0`/`2^255`).
- GBNF constrains llama-cpp to real ABI names + declared-external/`$ret` tokens (see `../fuzzer/`);
  anthropic/claude-code emit free-form JSON.
- **Editing the grammar is rule-governed → load [`../../../rule/update_grammar.md`](../../../rule/update_grammar.md) first.**
- **GBNF stability:** every Solidity arg/array type is a NAMED rule (`_arg_rule`→`aux_rules`),
  referenced not inlined — keeps the grammar under llama.cpp's repetition-expansion limit
  (inlining `bytes[]`/multi-array sigs blew it → server SILENTLY drops grammar → free sampling).
- **Per-width numeric caps + tuple exclusion (`_arg_rule`):** one NAMED rule per integer width —
  `uint{N}-arg` caps hex to N/4 digits (EXACT), `int{N}-arg` caps decimal to len(str(2^(N-1)))
  digits (APPROXIMATE — Tier-2 `_normalize_arg` clamp is authoritative), `bytesN-arg` = 2N hex.
  Widths via `fuzzer/arg_sampling.type_width`. Tuple-typed functions are dropped from the call pool
  by `interface_eligible` (Class A: pool == interface == grammar), so there is NO `tuple-arg` rule.
  llama-server returns 200 + no error on a parse failure, so `complete()` runs a one-time
  `_ensure_grammar_active` probe (temp0, root forces leading `[`); on rejection it degrades to the
  generic fallback grammar + logs ERROR. Prompt caching (`cache_prompt:true`) verified ~27× on the
  warm shared prefix; the probe is `cache_prompt:false`+once, so it doesn't disturb the cache.

## Output contract
`generate()` → `list[FuzzInput]`. Full call/arg vocab (bare vs `"<var>.<method>"`, `$ret`/`max`/`now`/
external-var args, reentrancy sentinel) = the **fuzzer's** contract → `../fuzzer/.README_AGENT.md#fuzzinput-format`.
`caller_hints` per strategy never include `deployer_address`.

## Add a strategy
`action_dim` / `state_dim` are now instance-synced (RL Iter 6) — you do NOT bump them by hand; the
`_action_table` length and encoder width follow the roster automatically. But update the FULL-roster
widths the encoder depends on:
- gen: `GENERATION_STRATEGIES` + `GENERATION_STRATEGY_PROMPTS` (no `deployer_address` in caller_hints) ·
  update `StateEncoder.NUM_STRATEGIES` (`../fuzzer/state.py`) · update `RLConfig.action_dim` DEFAULT (the
  empty-blocklist ablation size).
- mut: `MUTATION_STRATEGIES` + `MUTATION_STRATEGY_PROMPTS` + `_mut_<name>` on `LLMMutator`
  (`../fuzzer/mutator.py`) + `_MUTATION_STRATEGIES_FOR` · update `StateEncoder.NUM_MUT_STRATEGIES` +
  `RLConfig.action_dim` DEFAULT.
