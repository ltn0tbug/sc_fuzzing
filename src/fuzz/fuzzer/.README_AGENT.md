side). Reward semantics → `../rl/.README_AGENT.md`; LLM authoring → `../llm/.README_AGENT.md`. Commands → `../../../COMMANDS.md`.

## FuzzInput format
```python
FuzzInput(calls=[[name, args_list, value_wei_int, caller_name_str], ...], description="...")
```
- `name` = bare target fn OR `"<var>.<method>"` (declared external).
- `caller_name` ∈ strategy `caller_hints` (never raw hex; never `deployer_address`).
- arg ∈ {scalar, 40-hex addr, `"$ret<idx>"`(earlier call's single return), external `<var>`(its
  addr), `"max"`, `"now"`, array of those}.
- reentrancy setup sentinel (first call):
  `["atk.setReentrantCall", {"reentrant_func":"claimRewards","reentrant_args":[],"max_count":3}, "0x0", "attacker_address"]`
  — `reentrant_func` = **bare** target fn; `_build_reentrancy_test()` builds the sig from the ABI;
  GBNF constrains it to real ABI names. Configures the unified `Attacker` at `attacker_address`.

## Declared-external + `$ret` chaining (fork)
Oracle drain/supply checks stay main-target-only, but a FuzzInput may call **declared non-target
contracts** + **chain a return into a later arg** (price-oracle/DEX exploits, e.g. PLN).
- `extend.external` declares named vars (so a magic on-chain addr the LLM can't guess gets a name). Two
  kinds, switched by `abi`: **CALLABLE** `{var,interface?,address,abi}` → interface + `address constant`;
  head `"<var>.<method>"`→`IInterface(<var>)` AND usable as a `<var>` arg. **DATA-ONLY** `{var,address}`
  (no abi) → `address constant` only (victim/holder/pair/token-as-arg); arg-valid, not callable. Sets:
  `_external_consts`=all (arg), `_external_callable`=interface-bearing (head); decls skip iface for data-only.
- `$ret<idx>`: a call with a single return referenced later renders `T _ret<idx> = <call>;` (no
  try/catch — revert breaks the chain, as in a hand PoC); idx = producer's 0-based pos. Unreferenced
  calls keep the revert-tolerant try/catch.
- arg sentinels (`_arg_expr`): external `<var>`→addr const · `max`→`type(uint256).max` ·
  `now`→`block.timestamp` · `$ret<idx>`→bound local (or `0`).
- `extend.setup_template` set → load that full contract, substitute only `${calls_code}` (external
  decls/mocks baked in; stamped from `fork.sol.tpl` by `utils/gen_setup_template.py`). Unset
  → built-in `fork.sol.tpl` + runtime-injected decls.
- prompt/grammar: `external_prompt_section()` lists callables (with sigs) AND data-only named addresses +
  `$ret` rule (empty⇒unchanged); GBNF adds `call-ext-<var>-<method>` per method, puts every var in
  `name-val`, and extends `addr-arg-val` so target-call address slots accept var names / `target_address`.
- removed `swap.exec`/`flashloan.exec` hardcoded sentinels stay removed — this mechanism is general.
- **fork setUp has no deployer**: `fork.sol.tpl` only makes/funds attacker+reentrancy (the target already
  exists on-chain). `deployer_address` stays declared in `Harness.sol` but unset — never a caller/arg in fork.

## Arg rendering = two-tier type defense + callable action space (rule-governed → `rule/update_arg_rendering.md`)
Argument correctness is defended in **two tiers** so a bad literal never wastes an iteration on
`CompileError` (silent — `forge build` fails, scores 0 coverage):
- **Tier 1 (generator):** every path we control (RandomFuzz, sscfuzz random fallback, the corpus
  mutator, GBNF) routes numeric/bytesN draws through `arg_sampling.coerce_scalar` so a `uint16`
  stays a real uint16 and a `bytes32` is full-width. Non-grammar LLM (Claude) is uncontrollable →
  Tier 2 covers it.
- **Tier 2 (`_normalize_arg`):** the single render chokepoint. Dispatches on type family and COERCES
  — mask `uintN`, clamp `intN`, pad/truncate `bytesN` to 2N, ALWAYS decimalize numeric hex (an
  address-width `0x…` is otherwise typed `address` by solc). On a coercion failure it degrades to
  `_default_for_type` + logs WARNING via `_norm_default` (bumps per-iteration `_norm_fallback_count`)
  — **never returns a value verbatim**. `_arg_expr` resolves `$ret/max/now/alias` first, so
  `_normalize_arg` only sees literals. Widths parsed ONLY via `arg_sampling.type_width`.
- **Callable action space = `sol_interface.interface_eligible`** (drops any fn with a `tuple` in
  inputs/outputs, overload-aware). Applied at EVERY selection site — foundry `_abi_types`, mutator
  ABI tables, baseline selectors, GBNF `_build_gbnf` — so **pool == interface == grammar**. Tuple
  arg codegen is out of scope (see memory tuple-support-deferred).

## Oracle = net-profit value verdicts (fork DEX / off-fork mock DEX) + balance-delta heuristics, config-free
`fork.sol.tpl` (sets `forkMode=true`) measures attacker/reentrancy/target balances before↔after across
native coin + every ERC20 that moved (auto-discovered from `Transfer` logs via `vm.recordLogs`) + the
**target address itself** (catches no-`Transfer` internal-accounting drains). `snapshotState`/
`revertToState` reads before-balances of post-run-discovered tokens; sequence runs **once** (not
FinanceFuzz — we author the bug sequence, no differential T→T′).
- **4 signal names, TWO k=v line shapes** (one `console.log` each; `_emitHeuristic` / `_emitValueVerdict`
  over the low-level `_emitLine`). Currency is always a human SYMBOL, never `native|erc20`. The magnitude
  key encodes the unit: `value=` = native numéraire wei (18-dec); `amount=` = ERC20 raw base-units:
  - native heuristic: `BUG_SIGNAL: <name> tier=heuristic asset=<SYM> value=<wei>`
  - ERC20 heuristic:  `BUG_SIGNAL: <name> tier=heuristic asset=<SYM> token_address=<addr> amount=<raw>`
  - value verdict:    `BUG_SIGNAL: <name> tier=high total_asset=<count> target_asset=<SYM> value=<wei>`
  `asset` = the native coin symbol (`_nativeSymbol`: ETH/BNB/AVAX/FTM by chainid, default ETH) for a native
  move, else the ERC20's `symbol()` (`_erc20Symbol`, gas-capped/revert-proof) or `UnknownERC20Token` when it
  has none. `token_address` is present ONLY for an ERC20 heuristic (omitted for native).
  - **value verdicts (tier=high, ALL modes — the ONLY high tier):** `attacker_profit` (net numéraire value
    of the attacker bag — the single attacker, native + every token — is `> start`), `target_loss` (target
    holdings worth `< start`). FP-free by construction (net `> 0`). `total_asset` = how many holdings were
    summed (native + every watched ERC20); `target_asset` = the **native coin SYMBOL** (`_nativeSymbol`:
    ETH/BNB/AVAX/FTM by chainid, default ETH inline) — the numéraire is the wrapped-native token
    (1:1 with the coin, priced against its address) but is LABELED with the plain native coin;
    `amount` = the net-worth delta in that numéraire. **Pricing venue is chosen by `forkMode`, not the
    presence of the verdict:** on a fork (`forkMode=true`) every token is priced at slippage-aware DEX
    quotes; off-fork (`forkMode=false`, inline/legacy) `_pricingVenue` returns the **mock/empty DEX**
    (router 0), so tokens price to 0 and the verdict values **native 1:1 only** — a native-coin net profit
    still proves the high tier (`amount`=native delta), a token-only profit degrades to the heuristics. No
    real DEX needed inline, and NOT the removed numéraire-free Pareto rule (deleted 2026-07-05).
  - **balance-delta heuristics (tier=heuristic, all modes):** `attacker_gained` (any asset; reentrancy
    profit lands on the unified attacker), `target_drained` (target balance `<80%` of before, `>20%`
    threshold). The attacker GAIN check scans **every** watched asset; the DRAIN check counts
    only the TARGET's own holdings dropping (an external pair/router/LP legitimately loses balance in a
    swap → not a loss *on* the target). `>20%`-drain is sound because the sequence runs AS the attacker.
  - **Numéraire/venue** (`_pricingVenue`): off-fork (`!forkMode`) → the mock/empty DEX (router 0, native-only);
    on a fork, by `block.chainid` — UniV2-compatible router + wrapped-native + stable hop for
    mainnet/bsc/arbitrum/avalanche/base/fantom; unknown fork chain → router 0 → tokens price to 0 (native
    still counted), never an over-count. `_quoteToNumeraire` = gas-capped
    `staticcall{gas:200000}` `getAmountsOut` over `[token,wrapped]` then `[token,stable,wrapped]`; any
    failure → 0. (No supply-inflation/`totalSupply` invariant — removed 2026-06-27. `costfree_burn`/
    `pair_imbalanced` dropped — subsumed by value-based `attacker_profit`.)
- single-source: oracle + the unified `Attacker` live in ONE `templates/Harness.sol` (`abstract contract
  SCFuzzHarness is Test`: `_beginOracle`/`_runOracle`/`_watchedTokens`/`_afterState`/`_emitErc20Signals`/
  `_emitLine`/`_emitHeuristic`/`_emitValueVerdict`/`_nativeSymbol`/
  `_pricingVenue`/`_quoteToNumeraire`/`_portfolioValue`/`_emitValueVerdicts`/
  `_emitNativeHeuristics`/
  `_erc20BalanceOf`). **`_beginOracle()` + `_runOracle()` take NO args** — the actor addresses are
  harness state (`target_address`/`attacker_address`) and the pre-call snapshot is the `_snapId` state var
  set by `_beginOracle` (which also does `vm.recordLogs`). Every "before" balance (native included) is
  re-read AFTER the rewind inside `_runOracle` — the test body captures/threads in nothing; its fuzz fn is
  just `_beginOracle(); <calls>; _runOracle();`. (The old separate reentrancy actor was unified into
  `attacker_address`.) All 3 tests
  `import "./Harness.sol"` + `contract FuzzInputTest is SCFuzzHarness`; only setUp+fuzz body(+fork decls)
  in the per-mode tpl. The `Attacker` (`enum Mode{NONE,REENTRANCY,FLASHLOAN}`, `setReentrantCall`,
  `setFlashloanCall` **stub**, `_dispatch` on `receive`/`fallback(bytes)`) is deployed at `attacker_address`
  in every setUp; its `receive()` gates `_dispatch` on `gasleft()>2300` so a `.transfer`/`.send` payout to
  the now-contract attacker is accepted rather than reverting. `_write_harness_file()` (cached `_HARNESS_SOL`) copies it next to the test on every
  `compile()`/`run_input()`; fork validator too.
- no per-row token hint (former `BUG_TOKEN`/`extend.bug_signal_token` verified redundant, removed). A
  deployed **local** target emits the heuristic vocab too (SmartBugs `BECToken` batchOverflow →
  `attacker_gained asset=<SYM> token_address=…` off-fork; off-fork the mock/empty DEX prices native-only, so a
  **native** profit reaches tier=high but a token-only profit stays tier=heuristic — only the
  DEX-*priced* token valuation is fork-only); created before snapshot so
  `revertToState` keeps its code.
- **ERC20 probe gas-capped** `staticcall{gas:100000}` (`_erc20BalanceOf` in Harness.sol): real read
  <5k gas; without cap a non-token target whose `fallback()` does work (deposit-on-fallback) OOGs the
  test when probed (state change in static ctx = gas-consuming halt).

## Coverage (`coverage.py`) — replaces `forge coverage`
**1 fused forge call/iter once the target address is known** (`run_input`): `--json -vvv --debug --dump`
in one process — outcomes from stdout JSON, coverage from the dump's `debug_arena` filtered by
address (not `identified_contracts`, which `--json` blanks). Fork mode has the address up front
(`ForkConfig`); inline **learns + caches** it (`_target_addr_cache`, `_resolved_target_addr`) on the
first pass, which still takes **2 calls** (the 2nd, no-`--json`, keeps `identified_contracts` for the
name→address lookup) — every later iter fuses. Fusing is byte-identical to the old split, just removes
one forge startup/fork per iter (bigger win on fork). CompileError skips the 2-call dump entirely.
JUMPI = branch only if its source-map offset is inside an AST branch node (`forge build --ast`; regex
fallback). Stable test name `__sc_fuzz__.t.sol` + absolute paths (random names/relative paths break
`identified_contracts` on macOS `/tmp`→`/private/tmp`).
**OOM guard on the `--debug --dump` pass** (`_run_forge_bounded`): forge holds the whole step arena in
RAM before writing the dump, so one pathological input (LLM call → gas-bounded runaway loop; CFToken hit
4.8→8.2 GB) can OOM-kill the host *before* the post-hoc `_MAX_DUMP_BYTES` file cap ever sees a dump. A
watchdog thread polls the forge process-group RSS (`ps`, macOS-safe — no `ulimit`/`/proc`) and SIGKILLs
it past `_FORGE_MEM_CAP_MB` (default 3072, env `SC_FUZZ_FORGE_MEM_CAP_MB`). Fused call killed → drop the
whole iteration (`out_of_gas`); 2-call dump killed → keep the outcome, skip only that iter's coverage.

**Fork coverage fidelity = anchor on the ON-CHAIN bytecode, not the artifact.** On a fork the arena
executes the DEPLOYED code, but the recompiled artifact may not reproduce it (solc/optimizer/evm
drift). Two-tier fix:
- **Phase B (scaffold.py):** pin the exact on-chain compiler settings on EVERY fork build —
  optimizer/runs/evm_version into `foundry.toml`, and the target's `pragma` tightened to the exact
  meta.json solc version (`_pin_target_pragma`; a `^0.4.16` source deployed with 0.4.19 would else
  auto-detect the newest installed 0.4.x). Recovers all 25/25 rows to opcode-LCP≥0.98.
  - **Pre-Constantinople targets (`ForkConfig.coverage_evm_version`, set by `scaffold._coverage_evm_override`):**
    `evm_version` is GLOBAL per `forge build`, so an old target needing byzantium (Bancor 0.4.26 —
    deployed `EXP/DIV` dispatcher, solc default = byzantium) can't share the build with forge-std's
    constantinople-only `shl`. So `compile()` does a SEPARATE target-only coverage build
    (`--skip 'test/*' --evm-version byzantium --out out_cov`) that forge-std never sees; the harness
    build stays modern. Only solc < 0.5.5 rows (BEC, Bancor) trigger it (one extra local compile).
- **Phase A (`load_bytecode_meta(onchain_bytecode=…)`):** `compile()` fetches the executing runtime
  code via `eth_getCode` at the fork block (`_fetch_onchain_bytecode`; resolves the EIP-1967 impl for
  a proxy, else `ForkConfig.code_address`=meta impl), and `opcode_lcp(artifact, on-chain)` < 0.98 (or
  a failed fetch) → `coverage_unreliable=True` + ONE WARNING/contract. Flag rides `BytecodeMeta →
  FuzzResult/CoverageStats → run_log summary → _summary.json` for EDA.
- **Phase C (always correct):** `total_bc_branches` denominator = `2×len(on-chain JUMPIs)` (numerator
  arena PCs already live in on-chain PC space → correct ratio regardless of drift); **function**
  coverage from the on-chain dispatcher (`parse_dispatcher` selector→body-entry PC, hit iff that PC
  executed; ABI-named via the artifact's version-independent `methodIdentifiers`). SOURCE line/branch
  stays on the artifact map but is SUPPRESSED (0/0) when `coverage_unreliable`. Inline is always
  reliable/artifact-anchored (own freshly-deployed code).
- **Proxy (`ForkConfig.code_address`/`is_proxy`):** the impl's delegatecall frame is recorded under
  the IMPL address, so the coverage dump is filtered by `_resolved_code_addr()` (impl), while
  calls+oracle stay on `target_address` (proxy). Snood: bc 9/630 (proxy dispatch) → 173/608 (impl).
  A non-EIP-1967 proxy whose impl can't be resolved falls back to the meta impl + flags unreliable.
- Changes fork **reward** numbers (bc denominator now on-chain) — don't pool with pre-fidelity runs.

**Fork-RPC reliability (`run_input` retry).** A fork run can fail with NOTHING wrong in the fuzzed
calls: the public archive RPC behind `vm.createSelectFork` rejects a request — at createSelectFork
SETUP *or* on a MID-EXECUTION `eth_getStorageAt` (5xx / timeout / rate-limit). Either aborts the
`--debug --dump` pass with "debug arena is empty" (the SYMPTOM, on stderr); the true cause is a
`sharedbackend`/HTTP-error line on stdout. `_detect_fork_rpc_failure(stdout, stderr)` (module-level)
scans BOTH streams → `_parse_result` labels it `forge_status="SetupFailed"` /
`revert_reason="fork_setup_failed"` and puts the real cause in `raw_reason`. `run_input` then RETRIES
(`_FORK_RETRY_ATTEMPTS=3`, linear backoff) — ONLY on `fork_setup_failed`, never a compile error /
genuine revert / bug signal — and ROTATES the endpoint via `_set_fork_endpoint` (rewrites the
foundry.toml `[rpc_endpoints] <chain>` url) when `ForkConfig.rpc_endpoints` has spares. Endpoint list
+ pre-flight health/warm gate live in `src/experiment/run/scaffold.py` (`RPC_ENDPOINTS` is
chain→**list**, `preflight_fork`).

## Corpus (`mutator.py`) + paths (`paths.py`)
Admission unconditional; `add()` curation = Group A (AFL-favored minimal coverer) ∪ Group B (**weak-signal
bug witnesses** — RL Iter 7 C6: leanest rep of each distinct path among `bug_signal_found AND NOT
high_bug_signal_found` heuristic-tier near-misses; high-signal exploits EXCLUDED — already banked,
path-gated → no re-mutation value), bounded ≤10. Seed selection **uniform** over the union (`strategy` arg
accepted but ignored). `paths.is_distinct_path` (Jaccard < 0.9) = the single "distinct exploit" def
(reward gate + Group B). `CorpusEntry.high_bug_signal_found` carries the tier (fed from `FuzzResult`).

## Templates (`templates/`)
`string.Template` (`${var}`) to avoid Solidity `{value:…}` clash. `_build_test()` routes by pragma:
`inline.sol.tpl`(≥0.8) / `inline_legacy.sol.tpl`(<0.8) / `fork.sol.tpl`. Each `import "./Harness.sol"` +
inherits `SCFuzzHarness`; `Harness.sol` has **no** `${…}` (copied verbatim).
- **ctor args (local):** `extend.constructor_args` (positional, zipped w/ ctor ABI; addr params accept
  `deployer_address`/`attacker_address`, reject `target_address`) +
  `extend.constructor_value` (payable wei). `_constructor_render()` → `new T{value:}(…)` (modern) /
  `abi.encode`+`create` (legacy). None → type-default sentinels. Ignored in fork.
- **co-located dep deploy:** `extend.pre_deploy`/`extend.setup_calls` (`_dep_setup_render()`). Sibling
  contract in the **same source file** deployed in `setUp()` before target, bound `_depaddr_<alias>`
  (`pre_deploy=[{"contract":"Log","name":"log"}]`); alias resolves in `constructor_args=["log"]` or
  `setup_calls=[{"fn":"SetLogFile","args":["log"]}]` (gas-safe low-level call). Legacy
  `vm.getCode("<file>.sol:<Dep>")`+create; modern `new <Dep>()`. Deploys/calls only what source defines
  (no answer-key) → makes target *runnable* not *exploited*. Lifts SmartBugs reentrancy "codeless Log →
  Deposit reverts" (reentrancy 6→18, smartbugs 21→33). Round-trips via `_dataset_io._RUNTIME_EXTEND_KEYS`.

## bug-path gate
`result.bug_signal_found` set whenever a `BUG_SIGNAL:` appears (always reported — **recall**);
`_postprocess_result` also parses each line into `result.bug_signals`
(`[{name,tier,asset,token_address,total_asset,target_asset,amount}]`) and sets `result.high_bug_signal_found` = `any(tier=="high")`
(**precision** — a proved net profit/loss; surfaces as `signal=High` in the LLM history). The path-gated 0/1
`new_exploit_path` that drives **reward** (tiered: high=50, heuristic=5, max-not-sum) →
`../rl/.README_AGENT.md`.
- **run-log `fuzzing_output` keys** (built once in `report.build_fuzzing_output`, shared by
  `orchestrator.py` + baseline `loop.py`): `signal_found` (=bug_signal_found), `high_bug_signal_found`, `novel_path`
  (=bool new_exploit_path), `signals` (the structured list — supersedes `bug_type`). `bug_found`
  (=signal_found) + `bug_type` are kept as **legacy aliases** for the not-yet-migrated analysis layer
  (DataFrame column `bug_found_any`). Per-line coverage id/count dumps were dropped; `lines_this_run`/
  `functions_this_run` stay (consumed by `utils/build_summary_xlsx.py`).
