## Schemas (each file MUST validate)
Envelope: `{dataset,kind,schema,source_repo,description,generated_by,total_contracts,meta,contracts}`
(`total_contracts == contracts.length`). **NORMALIZED** — each fact lives in exactly one layer;
the loader re-joins by `id` (so a row is edited in one place). Record shape per layer is in `schemas/`:
| file | schema | content |
|---|---|---|
| `raw.json` | [`schemas/raw.schema.json`](schemas/raw.schema.json) | facts (category/target_contract/compiler/source/fork/provenance); ALL contracts; no skip/poc — single source of truth |
| `manifest.json` | [`schemas/manifest.schema.json`](schemas/manifest.schema.json) | curation only (skip/skip_reason/validation incl. canonical reference_exploit); ALL contracts; joined to raw by id |
| `enrich.json` | [`schemas/enrich.schema.json`](schemas/enrich.schema.json) | runnable only (skip=false): `{id, poc, extend}` — facts NOT duplicated, joined from raw/manifest |
Validate snippet → `../../../COMMANDS.md`. `enrich.extend` = runtime-ONLY per-kind bag
(external/setup_template · ctor/dep-deploy); derivable facts live in raw/manifest (the loader
re-derives them). Fork `extend` also carries `evm_version`/`optimizer`/`optimizer_runs` (build
fidelity) + `proxy`/`implementation` (coverage anchors on the impl for a proxy) — all re-derived
from raw `provenance` by `_build_extend`. `poc.calls` = `[name,args,value,caller]` (enrich schema + fuzzer `FuzzInput format`).
`extend.external` items are callable (`{…,abi}`) or data-only (`{var,address}`) named vars — shape +
authoring convention in `enrich.schema.json` / `rule/update_dataset.md`.

## Loader (`schema.py`)
JSON source paths are dataset-folder-relative; loader rewrites to repo-relative `data/...`
(callers do `ROOT / contract.source.dir`). Code-vs-data split: `_HERE` = this dir, `DATA_DIR`
= repo-root `./data/`. Keys: `"smartbugs"` | `"defihacklabs"`.
```python
from schema import load_dataset, load_all, load_manifest, load_raw
ds = load_dataset("smartbugs")          # ENRICH⋈RAW⋈MANIFEST → runnable Contract records (run/ uses)
all_ = load_all("defihacklabs")         # RAW⋈MANIFEST⋈ENRICH → every contract incl. skipped (eda/ uses)
```

## Pipeline
All tooling lives in repo-root `../../../utils/` (shared utils dir) and writes its output into
`./data/` — **never** under `src/`:
`ref/ + Etherscan → utils/build_*/fetch_* → utils/restructure_datasets.py → data/<ds>/source/ + raw/manifest/enrich.json;
 utils/validate_pocs.py · utils/validate_defihacklabs_{pocs,bugsignal}.py → manifest + enrich.`
Validators r/w via `../../../utils/_dataset_io.py` (flat shape on load, re-split on save; raw immutable).
DeFiHackLabs `source/` gitignored (re-fetchable); SmartBugs `source/` tracked.
